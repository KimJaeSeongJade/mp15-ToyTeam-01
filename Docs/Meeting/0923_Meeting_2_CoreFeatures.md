>

> 
> - 여러 종류, 체력이나 속도, 점수가 다르다, 사망시 소리

> 
> - 체력이 존재하고 체력이 다 달면 점수와 버틴 시간 보여주고 메인 화면으로 돌아가는 기능
> - 무기에 대한 정보가 있다
> 
> #### (5) 무기 시스템
> 
> - 발사체에 대한 정보, 무기 이펙트, 무기 종류, 과열 시스템, 발사시 종류에 따라 다른 소리 발생
> - 무기 종류 : 히트 스캔식, 투사체 발사 형식, 범위 타격 형식
> 
> #### (6) UI 시스템
> 
> - 체력 UI, 과열 UI, 피격시 UI, 무기 슬롯 UI, 점수 UI
> - 메뉴, 타이틀, 스테이지 선택 UI, 사망시 UI
>
