>

> - 공영서 / 1인칭 시점의 디펜스 게임, 로직이 직관적이었다
> - 김태현 / 게임이 재미있어보여서 만들고 싶었다
> - 장영환 / 프로젝트 기간에 완성할 수 있을 것 같았다
> - 정재윤 / 참고할 레퍼런스가 이미 많이 있었고, 기능 추가가 용이할 것 같다 (맛있다.)
> - 주성재 / 로직이 직관적이서 구상 시간이 길어질 것 같지 않아 선정했다 (맛있다2.)

> - 장영환 / 팀명 제시 : `말랑카우`, 팀원이 말랑하면 좋겠다

> - 주성재 / 팀명 제시 : `박치기공룡`
> - 공영서 / 팀명 제시 : `마감디펜스`
> - 김태현 / 팀명 제시 : `저는 잘 모르겠네요 이름 짓는 재주가 없어서`
> - 장영환 / 팀명 제시 : `분홍햄버거`
> - 장영환 / 팀명 제시 : `저는 잘 모르겠네요 팀 명 짓는 재주가 없어서`
