# 감튀모임 그라운드 룰

## 소통

#### (1) SLACK 과 DISCORD의 분리

#### 1. SLACK

- 기본적인 소통 수단으로 사용한다
- 임시적인 문서만을 관리한다
- 외부자료, 레퍼런스를 공유한다

#### 2. DISCORD

- 통화, 화면 공유를 위해 사용한다

#### (2) 메시지 규칙

- 메시지를 확인했을 때에는 ✅ 이모지를 사용하여 확인한 상태임을 알린다
- `@이름` 으로 언급한 질문에 대해서는 스레드를 사용하여 답변한다
- `@here` 는 긴급 상황에서만 사용한다

#### (3) 회의 규칙

- 다른 사람의 의견 제시 중에는 새로운 의견을 제시하지 말아야 한다
- 의견 제시 단위를 확실하게 끝맺어야 한다
- 새 의견을 제시할 때에는 손을 들어야 한다

#### (4) 상호 존중 ♥️

- `@이름` 으로 프로젝트에 관련하여 언급할 때에는 작업 가능 시간을 확인한다
- 작업 가능 시간에는 15분 이내에 확인 표시를 남길 수 있도록 한다

## 일정

#### (1) 작업 가능 시간

#### 1. 개인별

- 학원에 있는 시간은 모두 참여 가능

| 이름 | 평일 | 주말 |
| --- | --- | --- |
| 주성재 | `20:00 - 02:00` | `09:30 - 01:00` |
| 장영환 | `20:00 - 01:00` | `12:00 - 00:00` |
| 공영서 | `19:00 - 00:00` | `12:00 - 17:00` |
| 김태현 | `21:00 - 02:00` | `09:00 - 00:00` |
| 정재윤 | `22:00 - 02:00` | `23:00 - 01:00` |

#### 2.종합

| 평일 | 주말 |
| --- | --- |
| `22:00 - 00:00` | `23:00 - 00:00` |

#### (2) 일일 회의 시간

#### 1. 평일

| 오전 | 오후 |
| --- | --- |
| `09:30` | `17:00` |
- 오전 회의는 작업 현황 공유 목적으로 가볍게 진행한다
- 오후 회의는 프로젝트의 방향성에 대해서 진행한다 (기능 구현, 업무 분담 등)

#### 2. 주말

| 주말 |
| --- |
| `23:00` |
- 주말 회의는 진척도를 확인하는 느낌으로 메신저로 진행한다
- 필요 시, 팀장 주도 하에 디스코드에서 회의를 진행한다

## 자료 형식

#### (1) 마크다운 문서명

- Git 에 올라가는 문서는 **영문 PascalCase** 로 작성한다 (한글 파일명 깨짐 방지)
- 레포 자체가 팀 공간이므로 팀 이름은 생략한다

| 문서 종류 | 형식 | 예시 |
| --- | --- | --- |
| 날짜가 필요없는 문서 | `문서제목` | `GroundRules.md` |
| 날짜가 필요한 문서 | `MMDD_문서제목` | `1225_Presentation.md` |
| 회의록 | `MMDD_Meeting_내용` | `1225_Meeting_TopicSelect.md` |
| 업무일지 | `MMDD_이니셜` | `1225_YH.md` |
| 양식 | `내용_Template` | `DailyLog_Template.md` |

#### (2) 스크립트 명

| 스크립트 형식 | 형식 | 예시 |
| --- | --- | --- |
| 인터페이스 | `I인터페이스명` | `IDamageable.cs` |
| 클래스 | `PascalCase` | `MyClass.cs` |
| 추상클래스 | `추상클래스명Base` | `MonsterBase.cs` |
| 싱글톤 | `싱글톤명Manager` | `GameManager.cs` |

#### (3) 공유 파일 명

| 종류 | 형식 | 예시 |
| --- | --- | --- |
| 파일 | `날짜_내용` | `0923_TURRET.zip` |
| 양식 | `내용_양식` | `오류보고서_양식.docs` |
| 사고 동영상 | `ERROR_내용.mp4` | `ERROR_총알장전이안돼요.mp4` |
